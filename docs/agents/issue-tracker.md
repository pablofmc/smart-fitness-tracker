# Issue tracker

Tasks are GitHub Issues in `pablofmc/smart-fitness-tracker`, grouped by milestone. Use the `gh` CLI.

- Milestones: `M0 Garmin spike` to `M7 Correlations`, plus `Later`.
- Labels: `area:ui`, `area:data`, `area:sync`, `area:metrics`, `area:security`, `area:ops`.
- When a task is finished, tick its "Done when" boxes and close the issue.
